# Topic prompts for query writers

Write the question you would ask **if you did not know the answer**. You are shown broad areas only, never passages or document titles:
do not look up the documents, and use your own words.

- How the system is built, what services it consists of and how it is run  (document in English)
- Strengths, weaknesses and risks found in the current code base  (document in English)
- How the learning material about this system is organised  (document in Turkish)
- The overall architecture: query and indexing paths, workers, messaging  (document in Turkish)
- Retrieval techniques beyond plain vector search  (document in Turkish)
- Re-ordering retrieved results with a second stage: providers, safety, failure handling, measured results  (document in Turkish)
- Measuring retrieval quality: metrics, datasets, tuning discipline, human labeling  (document in Turkish)
- Caching of embeddings and of query results, and keeping cached answers correct  (document in Turkish)
- A recorded decision about which search strategy is the default  (document in English)
- A recorded decision about cache correctness after re-indexing  (document in English)
- A recorded decision about making ranking providers interchangeable  (document in English)
- What was found out about two external ranking services  (document in English)
